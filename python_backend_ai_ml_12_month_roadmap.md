## Recommended Stack
**Primary language:** Python

**Backend:** FastAPI + Pydantic + SQLAlchemy

**Database:** PostgreSQL

**Caching:** Redis

**Testing:** pytest

**Dev tools:** Git, GitHub, Linux, Docker, GitHub Actions

**AI/ML:** NumPy, Pandas, scikit-learn, PyTorch, Transformers

**AI apps:** Embeddings, RAG, vector storage, LLM APIs

## What NOT to do initially
- [ ] Don't learn Java + Spring + Node.js + Python simultaneously.
- [ ] Don't collect frameworks without building projects.
- [ ] Don't spend months only watching tutorials.
- [ ] Don't ignore SQL, Git, testing or deployment.
- [ ] Don't wait until the end of 4th semester to start applying.

## Java vs Python Decision
For this specific goal — **AI/ML + backend + product-based startup internship** — make **Python your primary language**.

You do NOT need to avoid Java forever. If a target company specifically requires Java/Spring Boot, learn that stack later for that role. Your first priority should be becoming genuinely strong in one stack rather than becoming shallow in several.

## One-Line Learning Order
Python → Git → DSA → SQL/PostgreSQL → FastAPI → SQLAlchemy → Auth → Testing → Linux → Docker → Deployment → ML → PyTorch/Transformers → RAG/LLM apps → Projects → Internship applications
